# slate 0.6.0

a foundations release. slate looks and behaves the same, but the app is wired
through hilt, navigation compose and room, and an update now keeps your habit
history through a one-time migration.

## highlights

### your history survives the update

habits used to live in a datastore json file. on first launch, `0.6.0` copies
them into a local room database, keeps every checked day and marks the migration
as done. settings and the focus list stay in datastore.

### focus reacts immediately

the accessibility service now collects settings live instead of reading them
once when it connects. starting a focus timer or editing blocked apps takes
effect right away, with the same protected-package safety list as before.

### reminders start reliably

reminder work is now created by hilt's worker factory, configured from the
application object. the default workmanager initializer is removed, so the
worker can receive the store it needs.

### quieter internals

the settings screen no longer polls every 15 seconds during focus, and the view
model no longer runs an infinite midnight loop. today refreshes when the app
resumes and the ui simply observes state.

release builds also enable r8 with keep rules for hilt, room, navigation, compose
and workmanager.

## install

```bash
adb install -r slate-debug.apk
```

or open the apk on the phone and allow installs from the app you used to
transfer it. on android 13 and newer, a sideloaded copy may need
**app info → allow restricted settings** before the accessibility service can be
enabled.

## checksums

the release publishes `slate-debug.apk.sha256` next to the apk. verify it with:

```bash
sha256sum -c slate-debug.apk.sha256
```

## what is inside

- version `0.6.0`, version code `8`
- min android 8.0 (api 26), target api 35
- 28 unit tests, lint with intentional warnings
- no internet permission, no account, no cloud, no tracking
- one-time datastore → room migration for habits from `0.5.1` and older
