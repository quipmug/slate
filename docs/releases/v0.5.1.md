# slate 0.5.1

a small reliability release: the first-run **begin** button now works, and the
strict focus blocker is safer on more devices.

## highlights

### begin works on the first run

the welcome screen used to intercept touches above the button. the ripple
appeared, but the tap gesture was cancelled before it could fire. the
interceptor is gone; `begin` is enabled immediately, dismisses the welcome and
remembers that it has been seen.

### focus can no longer trap the phone

before closing an app, the accessibility service now re-checks the live
protected list instead of trusting the stored one. settings, the dialer, the
launcher, system ui, the installer, the permission controller and slate itself
are always safe, even if the saved list is stale or edited externally. the list
also covers common samsung, xiaomi, oppo, oneplus and huawei packages, and the
manifest declares package-visibility queries for home, settings and dialer.

the timer itself is unchanged: pick apps, pick 1h, 4h, 8h or 24h, and they stay
closed until it expires. there is no stop button inside slate.

## install

```bash
adb install -r slate-debug.apk
```

or open the apk on the phone and allow installs from the app you used to
transfer it. on android 13 and newer, a sideloaded copy may need
**app info → allow restricted settings** before the accessibility service can be
enabled.
